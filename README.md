# GREEN API Test Task

## Description

This project was developed as a test assignment for GREEN-API.

The web page allows users to interact with GREEN-API methods by providing their own `idInstance` and `ApiTokenInstance`.

## Implemented Methods

* getSettings
* getStateInstance
* sendMessage
* sendFileByUrl

## Technologies Used

* HTML5
* CSS3
* JavaScript (Fetch API)

## Features

* User-defined connection parameters (`idInstance`, `ApiTokenInstance`)
* Sending text messages
* Sending files by URL
* Displaying API responses in a read-only field
* Responsive two-column interface based on the provided layout
